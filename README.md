# HH Developers

A modern business and developer website template built with HTML, CSS, and JavaScript.

## Included sections
- Hero banner with CTA
- Services overview
- Work / case studies
- Process steps
- Pricing cards
- Testimonials
- Contact call-to-action

## Run locally
Open `index.html` directly in your browser, or use:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

## Deploy on GitHub Pages
1. Open repository settings.
2. Go to Pages.
3. Select Deploy from a branch.
4. Choose `main` and `/root`.
5. Save.

Your website will be published at a URL like:

```text
https://<your-username>.github.io/hh/
```
